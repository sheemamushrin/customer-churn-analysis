# Customer Churn Analysis

## Project Overview
This project analyzes customer behavior data to identify the main reasons behind customer churn (subscription cancellations).

The analysis focuses on:
- Customer engagement
- Subscription usage patterns
- Behavioral trends
- Retention improvement strategies

## Objectives
- Identify factors contributing to customer churn
- Analyze customer activity and engagement
- Visualize churn trends
- Suggest retention strategies

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
